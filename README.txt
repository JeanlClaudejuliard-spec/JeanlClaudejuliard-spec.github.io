# Site — Amicale Bézenet de Marche et de Sorties

Site vitrine statique, gratuit et sans base de données.

## Fichiers
- `index.html` : contenu du site
- `style.css` : design responsive
- `script.js` : menu mobile + année automatique
- `images/hero.jpg` : visuel provisoire

## À modifier avant publication
1. Dans `index.html`, remplacez l'adresse e-mail provisoire `amicale.bezenet@example.com`.
2. Ajoutez votre vrai numéro de téléphone.
3. Remplacez les événements "À définir" par les vraies dates.
4. Remplacez les blocs de galerie par vos photos.
5. Vérifiez les mentions légales et la politique de confidentialité selon votre situation.

## Publication gratuite
Le site peut être publié gratuitement sur GitHub Pages, notamment avec une adresse `votre-nom.github.io`.
Il peut aussi être hébergé sur d'autres services d'hébergement statique gratuits.

Le formulaire actuel utilise `mailto:` : il ouvre le logiciel de messagerie du visiteur. Pour un vrai formulaire en ligne, il faudra connecter un service de formulaire ou une solution serveur.
